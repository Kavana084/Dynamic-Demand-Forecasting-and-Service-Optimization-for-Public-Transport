# Smart Public Transit Optimization System - Frontend

A modern, scalable ReactJS frontend for the Smart Public Transit Optimization System.

## Features

- **Dashboard**: System overview and KPIs.
- **Demand Prediction (CatBoost)**: Form to test passenger demand predictions.
- **Fleet Optimization (MILP)**: Interface for fleet allocation algorithms.
- **Dynamic Decision Engine (DRL)**: Interface for real-time recommendations.
- **Heatmap & Analytics**: Placeholder for geospatial visualizations.
- **AI Transit Assistant**: Chatbot interface for interacting with the system.

## Tech Stack

- ReactJS (JavaScript)
- Vite
- React Router DOM
- React Bootstrap
- Axios
- Lucide React Icons

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

## Environment Variables

Create a `.env` file in the root directory:

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```
